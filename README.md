# IntraspecificVariationInPSF
Intraspecific variation in plant-soil feedback: effects on cabbage rhizosphere microbiome and insect resistance. Microbiome, caterpillar and plant data analysis.   

Raw sequence data is openly available at the European Nucleotide Archive (ENA) at EMBL-EBI under study accession number PRJEB113814 (https://www.ebi.ac.uk/ena/browser/view/PRJEB113814).
